# FCC Survey Form

Learning exercise for **HTML forms & responsive web design**

## 🎯 Objective

**Main goal**: Build a responsive survey form meeting freeCodeCamp's Responsive Web Design certification requirements.

**Context**: This project is part of the freeCodeCamp Responsive Web Design certification. It focuses on creating accessible, user-friendly forms with proper HTML form elements, labels, and responsive CSS styling. Prerequisite knowledge includes HTML form elements and basic CSS layout techniques.

## 🛠 Tech Used

- HTML5 (forms, semantic elements)
- CSS3 (Flexbox, media queries)
- Responsive Design
